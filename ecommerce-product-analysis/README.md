# E-commerce Product Analysis

Учебный проект продуктового аналитика: анализ заказов, выручки, среднего чека, повторных покупок и каналов привлечения.

> Все данные синтетические и созданы исключительно для обучения. Они не относятся к реальной компании.

## Стек
- PostgreSQL, SQL
- Python, pandas
- Matplotlib
- CSV

## Структура
- `data/customers.csv` — клиенты, канал привлечения и регион
- `data/products.csv` — каталог товаров
- `data/orders.csv` — заказы и позиции заказов
- `sql/schema.sql` — создание таблиц
- `sql/analysis.sql` — аналитические SQL-запросы
- `analysis.py` — анализ данных и сохранение графиков
- `reports/` — сюда сохраняются графики при запуске

## Как запустить Python-анализ
```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python analysis.py
```

## Как запустить SQL
1. Создайте базу PostgreSQL.
2. Выполните `sql/schema.sql`.
3. Импортируйте CSV в соответствующие таблицы (порядок: customers, products, orders).
4. Выполните запросы из `sql/analysis.sql`.

## Бизнес-вопросы
1. Как менялась выручка по месяцам?
2. Какие категории товаров дают наибольшую выручку?
3. Какой средний чек?
4. Какие каналы привлечения связаны с большей выручкой на клиента?
5. Какая доля клиентов совершила более одной покупки?

## Важные оговорки
- Набор данных синтетический, поэтому результаты нельзя интерпретировать как рыночные факты.
- Конверсию сайта нельзя корректно вычислить только по таблице заказов: для неё нужны данные о посещениях/сессиях. В проекте она не заявляется как рассчитанная метрика.
